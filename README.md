# CyBarPrep

A web application project built with React, TypeScript tooling, Vite, and an Express server.

The repository includes dependencies for Supabase connectivity, PDF processing, document-oriented workflows, and optional AI-provider integrations. The precise user-facing functionality should be understood from the current source rather than inferred from dependencies alone.

## Technology stack

- React 19
- Node.js and Express
- Vite and TypeScript
- Supabase
- PDF parsing utilities
- React Markdown
- Google GenAI, Groq, and Hugging Face SDKs
- Tailwind CSS and Framer Motion

## Getting started

**Requirements:** Node.js and npm.

```bash
git clone https://github.com/erodion4776/CyBarPrep-2.git
cd CyBarPrep-2
npm install
npm run dev
```

## Build and type-check

```bash
npm run build
npm run lint
```

## Configuration and security

Configure external service credentials through environment variables. Keep API keys, Supabase privileged keys, authentication secrets, and user documents out of source control. Review access controls and document-handling policies before production deployment.

Evolving application. Confirm the implemented workflows, integrations, and deployment configuration in the source before relying on them.
